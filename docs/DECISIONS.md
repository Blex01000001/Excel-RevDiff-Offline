# 架構決策的理由

平常不用讀這份文件。只有在「想推翻或繞過某個決策」時才讀；決策清單本身在 `CLAUDE.md`，編號相同。
格式：決策 — 原因 — 不要做什麼。

1. **成品是單一離線 HTML，SheetJS 內嵌** — 使用者的公司電腦不能安裝軟體，網路可能擋 CDN — 不要引用外部資源（CDN、字型、圖片），不要讓成品變成多個檔案；圖示用內嵌 SVG data URI。
2. **原始碼分檔、由 `build.py` 組合；`index.html` 是產物但要 commit** — 分檔讓每次修改只需讀一個小檔；GitHub Pages 與使用者直接取用 repo 裡的 `index.html`，所以產物必須在 repo — 不要把程式合併回一個大檔，不要把 `index.html` 加進 `.gitignore`，不要引入打包工具（建置只用 Python 標準函式庫）。
3. **自己寫 .xlsx 匯出** — SheetJS 免費版寫檔不支援儲存格顏色 — 不要換回 `XLSX.writeFile`。
4. **設定要按「套用並開始比對」才執行，且載入後什麼都不預選** — 數萬列時勾一項跑一次太慢；使用者要自己決定 Key — 不要改回勾選就自動比對，也不要預設全勾。
5. **同 Key 的列先雜湊配對完全相同者，其餘在 `GREEDY_LIMIT` 內才做「差異最少」配對；重複 Key 不略過、警告預設收折** — 低區分度的 Key 會讓 A×B 兩兩比較爆量、頁面卡死（曾發生：預設 Key 是第一欄時跑 5 分鐘沒結果）；使用者要求「不要默默略過」但不想被訊息洗版 — 不要移除上限、不要把預設 Key 設成第一欄、不要刪掉或預設展開警告。
6. **數量差值是獨立的數字欄，儲存格只顯示 `舊 → 新`** — 方便篩選、排序、加總，匯出後在 Excel 也能用 — 不要再把 `+3` 標籤塞回儲存格。
7. **預設暗色主題、不跟隨作業系統；語言預設跟隨瀏覽器；兩者用 localStorage 記住** — 使用者指定 — 不要改回 `prefers-color-scheme`。
8. **讀檔、解析工作表、比對在 Web Worker 執行；Worker 原始碼＝內嵌的 SheetJS 文字＋以 `Function.toString()` 取出的函式；失敗時自動退回主執行緒** — 數萬列時主執行緒會凍結 2 到 6 秒，又必須維持單一 HTML — 不要拆成外部 worker 檔、不要把 SheetJS 改回主執行緒直接載入、不要移除備援。
9. **測試只供開發用，成品維持零依賴** — 使用者不需要也不會碰到 Node／Playwright — 不要為了測試在成品加任何東西（測試靠既有的全域名稱與元素 id）；測試檔當場產生，不要把二進位測試檔放進 repo；效能測試不放進 `npm test`（時間隨機器而變）。
10. **標題列固定（sticky）** — 使用者指定 — 不要移除。
